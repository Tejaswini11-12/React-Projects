# 📝 Feedback Form App

A simple React-based feedback application where users can submit feedback and view all responses dynamically.

## 🚀 Features

- Submit user feedback
- Display feedback dynamically
- Controlled form inputs
- Form validation
- Clean and responsive UI
- User avatar generation

## 🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>

Install dependencies:

```bash
npm install

Run the project:

```bash
npm run dev
